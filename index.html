KNOW BEFORE YOU RECOVER

Recovery safety guide

The first actions you take after data loss can determine whether recovery remains possible.

01

Stop using the device

Do not copy files, install software or format the affected drive. New writes can overwrite deleted data.

02

Do not run repairs first

Avoid CHKDSK, formatting and automatic repair on the original device until you have a safe image.

03

Image before scanning

For unstable media, use a reputable imaging tool with error handling. Work on the image, not the original.

04

Save elsewhere

Export recovered files to a different physical drive. Never write recovered data back to the source.

05

Know when to stop

Clicking, grinding, repeated disconnects or burning smells can indicate hardware failure. Power down and consult a professional recovery lab.

06

Understand SSD TRIM

On SSDs, TRIM may make deleted blocks unrecoverable. Avoid further use and seek specialist advice quickly.

i
What this web edition can and cannot do

It can scan user-selected files and disk images for supported signatures. It cannot enumerate physical drives, read raw sectors, reconstruct NTFS/exFAT metadata, reliably recover fragmented files, or defeat encryption/TRIM. Those functions require a signed native desktop recovery engine.
